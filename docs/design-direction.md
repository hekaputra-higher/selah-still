# Visual decisions

Warm paper #f7f4ed; forest ink #25372f; muted sage #e7ebe1. Georgia for Scripture and major headings; system sans for controls. Reading column at most 676px within 740px container. Scripture at 20–22px with generous line height. No hero photo competes with the text. Fine rules separate sections; buttons have at least 44px targets. Focus rings remain visible. Mobile navigation wraps deliberately; no horizontal scroll at 332px.

Cosmos observations should become testable choices: spacious references → narrow text column and generous margins; editorial type → readable serif Scripture; natural light → warm background; quiet movement → no required animation. Use inspiration without copying layouts or images.
